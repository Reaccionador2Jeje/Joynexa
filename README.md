# Joynexa

**The Gaming Universe** — una superplataforma gaming de AtDev para descubrir videojuegos, explorar comunidades y conectar experiencias de juego desde un único sitio web.

> Estado: prototipo web inicial en desarrollo.

## Primera entrega

Sitio estático responsive construido con HTML, CSS y JavaScript nativo. No requiere Node.js, compilación ni dependencias externas.

Incluye:
- Página de inicio y presentación de Joynexa.
- Catálogo de demostración con búsqueda y filtros.
- Diseño adaptable a móviles y escritorio.
- Secciones para Joynexa Play, Joynexa ID, Achievements, Social, Cloud y Events.
- Presentación del espacio para desarrolladores.
- Avisos claros para funciones aún no implementadas.

Los juegos del catálogo son tarjetas de muestra: no son juegos publicados ni ejecutables todavía.

## Ejecutar localmente

Abre el archivo index.html en un navegador o utiliza cualquier servidor estático local.

## Publicar en Cloudflare Pages

1. Abre Cloudflare Dashboard y entra en Workers & Pages.
2. Crea una aplicación Pages conectada a este repositorio de GitHub.
3. Selecciona la rama main.
4. Deja vacío el comando de compilación.
5. Usa el directorio de salida ".".
6. Despliega el proyecto.
