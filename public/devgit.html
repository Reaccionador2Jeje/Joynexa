Exportar trabajo

Descarga un diff de texto o exporta los archivos del proyecto. DevGit no publica commits en GitHub ni en otro servicio remoto.

Independencia y privacidad

DevGit funciona sin cuenta Joynexa y sin secretos de GitHub. Solo consulta la API pública de GitHub cuando importas un repositorio público, exclusivamente para descargar su código. Edición, ramas, historial y commits permanecen en IndexedDB de este navegador. No se envían commits a ningún servidor.
