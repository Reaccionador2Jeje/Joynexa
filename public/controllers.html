Controles virtuales

Estos botones envían las mismas señales que un mando físico. Sirven para probar juegos web adaptados a Joynexa.

Una sola API de entrada

Incluye /joynexa-input.js en tu juego, crea una instancia y escucha los eventos de botones y ejes. No necesitas integrar cada marca de mando por separado.

const input = new JoynexaInput.JoynexaInput();
input.addEventListener("button", ({ detail }) => {
  if (detail.name === "a" && detail.pressed) jump();
});
input.addEventListener("frame", ({ detail }) => {
  player.move(detail.axes.leftX, detail.axes.leftY);
});
input.start();

Los nombres A/B/X/Y siguen el mapeo estándar del navegador; algunos mandos genéricos pueden usar otro orden. No se envían datos del mando a Joynexa.
